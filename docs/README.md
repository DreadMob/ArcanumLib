# ArcanumLib Documentation

This folder contains API documentation for `ArcanumLib` — a shared Vintage Story modding library for client-side GUI rendering, color manipulation, and other cross-mod utilities.

## Available APIs

- [ImageIconCache](ImageIconCache.md) — load, cache and draw icon image surfaces with clipping and tinting.
- [RGBA](RGBA.md) — lightweight Cairo-friendly color struct.

## Target Framework

- .NET 10
- Vintage Story 1.22.1+
