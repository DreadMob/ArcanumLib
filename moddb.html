Arcanum Lib

Shared utility library for Vintage Story

Arcanum Lib is a client/server library for Vintage Story mod developers. It collects common patterns — GUI, HUDs, holograms, status effects, events, commands, data persistence, particles, and more — into one reusable assembly. The library does not add in-game content by itself; it is meant to be referenced by other mods as a dependency.

⚠️ Before you install

Arcanum Lib is a library mod and does nothing on its own. Install it only if another mod requires it, or if you are writing a mod that uses the ArcanumLib assembly.

🖥 GUI & HUDs

Cairo-based UI toolkit and reusable screen overlays for in-game information.

  • › HudPanel / HudDialog / HudClientSystem for packet-driven player HUDs
  • › Themed colour palette, layout spacing, and font size overrides
  • › PacketIconHud and TransientOverlay for timed icons and notifications
  • › Scrollable item lists, custom icon registry, radial menu, and date/time picker
✨ Holograms

3D floating text labels drawn in world space without heavy manual Cairo setup.

  • › SingleHologramRenderer and AreaHologramRenderer with chunk scanning
  • › Per-source text, colour, range, and height offset via IHologramTextSource
  • › Versioned Cairo texture caching with 3D-to-2D projection and distance scaling
  • › Optional per-line renderer for custom styles, progress bars, and separators
⚔ Status Effects

Timed buff and debuff system with a packet-driven icon HUD.

  • › Stacking, refresh, override, and independent application modes
  • › Configurable duration, charges, and attribute modifiers
  • › Built-in client icon HUD with timers and tooltips
⚡ Events, Actions & Commands

Cross-mod communication and command construction made simpler.

  • › Typed event bus with keyed subscriptions and diagnostics
  • › String-based action registry for quest and NPC triggers
  • › Fluent command builder with argument parsing and localizations
💾 Data & Persistence

Safe per-world and per-player storage helpers.

  • › Versioned ModDataStore with migration support
  • › Pity tracker, playtime tracker, and cooldown scheduler
  • › Validation helpers and typed config/JSON loaders
🧰 Helpers

Miscellaneous utilities used across many Vintage Story subsystems.

  • › Position/geometry, block search, and land/zone trackers
  • › Item stack builder, damage helpers, and chat formatting
  • › Particle builder, random weighting, text utilities, and categorized logging

For mod developers

Reference ArcanumLib.dll in your project and add this to your modinfo.json:

"dependencies": { "arcanumlib": "1.0.0-rc1" }

Full API documentation is included in the docs/ folder of the release archive.
