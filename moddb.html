Note. ArcanumLib is a utility library, not a standalone mod. Useful functions are available for any Vintage Story mod, but the API is driven by the Alegacy project set.

What it is

ArcanumLib is a low-level, instance-based shared layer for Vintage Story. Its strongest parts are the HUD/GUI, hologram, status-effect and particle systems — but it also covers persistence, events, actions, scheduling, networking and small utilities. It is the common ground under the Alegacy mods.

Arcanum Lib will keep expanding with new helpers and systems. If you have an idea, a missing utility, or a whole subsystem in mind, suggest it in our Discord — we will implement it.

What it is not

  • It does not add blocks, items, creatures, or gameplay on its own.
  • It is not a high-level framework that writes a mod for you.
  • It is not a guaranteed-stable public SDK.

Who should use it

Useful for any Vintage Story mod that needs the listed systems. The defaults and examples are oriented toward the Alegacy mods, so expect the API to move as those projects evolve.

Quick examples

using ArcanumLib.Persistence;

var store = ModDataStore.GetOrCreate<MySaveData>(sapi, "mymod", "state", 1);
store.Data.Counter++;
store.MarkDirty();
using ArcanumLib.Effects;

var svc = ArcanumServices.Get<StatusEffectService>()!;
var effect = new StatModifierEffect("mymod:swiftness", "walkspeed", 1.5f);
svc.Apply(entity, effect, durationMs: 10000, data: null);
using ArcanumLib.Particles;

var p = new ParticleEffectBuilder()
  .Count(8, 16)
  .Color(ParticleUtils.Colors.Fire)
  .Position(pos, 0.5f)
  .VelocityUp(0.2f, 0.6f)
  .Life(0.8f)
  .Gravity(-0.02f)
  .Size(0.25f, 0.1f)
  .Quad()
  .Build();
capi.World.SpawnParticles(p);

How to reference

Add ArcanumLib.dll as a dependency. Ensure ArcanumLibModSystem loads before your mod system, then resolve services through ArcanumServices.Get<T>() or ArcanumRuntime.Current.Services.
